# Ricordo — сайт

Страницы — самодостаточные HTML-файлы (CSS и JS внутри).
Внешних библиотек нет, подключаются только шрифты Google Fonts.

```
index.html          главная (эталон общего стиля, шапки и скрипта)
uslugi.html         форматы мероприятий
proekty.html        все проекты
proekt-*.html       страницы кейсов (генерируются)
kontakty.html       контакты и заявка
_build/cases.py     тексты и кадры кейсов
_build/build.py     сборка: python3 _build/build.py
img/, video/        фотографии и видео-петли с постерами
_zapas/             отобранные, но не вошедшие кадры
server.js           локальный просмотр: node server.js → http://localhost:8788
deploy.sh           выкладка демо на GitHub Pages
```

Порядок работы: общий стиль, шапку и скрипт правьте в `index.html`, тексты кейсов —
в `_build/cases.py`, затем `python3 _build/build.py` разнесёт изменения по остальным
страницам и пересоберёт кейсы. Что уточнить у клиента — в `сверить-кейсы.md`.

## Первый экран

Вместо фотографии — видео `video/hero-walk.mp4`: Анастасия выходит на сцену.
Играет один раз и замирает на последнем кадре, звука нет, зацикливания нет.
Постер `video/hero-walk.jpg` — первый кадр, поэтому при старте нет скачка.

Поверх кадра три световых слоя (`.spot`, `.sweep`, `.glow` внутри `#heroFig`):
пятно света на входе, один проход блика на 2,7 с и подсветка за курсором на десктопе.

При системной настройке «уменьшить движение» видео не грузится:
вместо него показывается `img/anastasia-stage.jpg` — последний кадр ролика, световые слои скрыты.

Заголовок первого экрана меняет одно слово по кругу: корпоратива → конференции → свадьбы → юбилея. Слово стоит на отдельной второй строке и выделено золотым, поэтому смена ширины
ничего не двигает: высота заголовка и позиция строки одинаковы для всех четырёх слов. Список слов — массив `words` в скрипте, интервал 3 секунды.
Смена останавливается, когда первый экран уходит из кадра или вкладка неактивна.
Для скринридеров в `<h1>` лежит неизменная фраза целиком, анимированная часть скрыта от них.

Видео пытается стартовать само. Если браузер запретил автозапуск (так бывает при
встраивании страницы в iframe), запуск происходит по первому действию посетителя,
а до этого показывается статичный кадр `img/anastasia-stage.jpg`.

## Что нужно подставить перед публикацией

| Где | Что заменить |
|---|---|
| все три файла | телефон `+7 968 624-38-07` |
| все три файла | домен в `canonical`, `og:url`, `og:image` — сейчас `ricordo.ru` |
| index.html, kontakty.html | ссылка на политику обработки персональных данных (`href="#"`) |
| index.html | блок `ANALYTICS SLOT` в `<head>` — код Метрики или GA |
| send.php | `$TO` — куда приходят заявки, `$FROM` — ящик на домене сайта |
| _build/build.py | реквизиты `OPERATOR`, `INN`, `OGRN`, `ADDRESS` — подвал, политика, согласие |

## Форма

Заявки принимает `send.php` — он лежит рядом с `index.html`. Работает на любом российском
хостинге с PHP (Beget, Timeweb, REG.RU): сохраняет заявку на сервере в `leads/leads.csv`
вместе с временем, IP и отметкой о согласии, затем пересылает письмом на `$TO`.

Как включить:
1. Залить на хостинг все файлы сайта вместе с `send.php`, `img/`, `video/`, `fonts/`.
2. В `send.php` вписать `$TO` (куда слать) и `$FROM` (ящик на домене, иначе письма уйдут в спам).
3. Отправить тестовую заявку: проверить почту и появление `leads/leads.csv`.
   Если письма не доходят, а файл пишется — на хостинге не настроена отправка почты:
   включить её в панели хостинга или перевести скрипт на SMTP Яндекс 360.

На GitHub Pages и на localhost PHP не работает. Там форма не отправляет заявку и прямо
пишет посетителю, что это демо, с телефоном и Telegram.

Без согласия (галочка) заявку не отправит ни форма, ни `send.php`. Юридические требования
и что сделать до запуска — в `юридическая-проверка.md`.

## Аналитика

Кнопки размечены атрибутом `data-ev`. Функция `track()` в конце файла уже умеет
`ym(YM_ID,'reachGoal',...)` и `gtag('event',...)` — достаточно подключить счётчик.

События: `cta_header`, `cta_hero`, `cta_menu`, `cta_telegram`, `cta_uslugi`,
`nav_works`, `call`, `mail`, `tg`, `form_submit`, `form_success`.

## Страницы услуг

Пять посадочных страниц — папками, чтобы адрес был вида `/organizaciya-korporativov-moskva/`.
Тексты, FAQ, сроки и кейсы каждой — в `_build/services.py`, шаблон — `_build/landing.py`.
Сборка `python3 _build/build.py` пересобирает их вместе с `sitemap.xml`.
На каждой странице своя разметка schema.org: Service, FAQPage, BreadcrumbList.

## Запуск на ricordo.ru — чек-лист SEO

Демо на GitHub Pages закрыто от поисковиков: `deploy.sh` при выкладке демо добавляет
`noindex` в каждую страницу и подменяет `robots.txt` на `Disallow: /`. В исходниках
этого нет — на боевой хостинг файлы заливаются как есть.

1. Залить на хостинг все файлы и папки сайта, включая `robots.txt` и `sitemap.xml`.
2. Проверить, что отвечают `200 OK`:
   `curl -I https://ricordo.ru/robots.txt` и `curl -I https://ricordo.ru/sitemap.xml`.
3. Убедиться, что в коде страниц нет `noindex` (на боевом сайте его быть не должно).
4. Добавить сайт в Яндекс Вебмастер и Google Search Console, подтвердить права,
   отправить `https://ricordo.ru/sitemap.xml` в обоих. Sitemap также указан в `robots.txt`.
5. После изменений в страницах: `python3 _build/build.py` — sitemap пересоберётся с новой датой.
